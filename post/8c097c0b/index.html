0097 dos命令(批处理)学习笔记之 echo rem cd dir(二)
2020-04-03 3 分钟阅读 min read

学习要点：

  1. 显示信息：echo
  2. 注释语句：rem
  3. 目录切换：cd
  4. 列文件名：dir

rem 命令

rem 为注释命令，一般用来给程序加上注解，该命令后的内容不被执行，有点类似咱们C# 里的 // 符号；但差别是这里的rem后面的字符串，在bat执行的时候能显示出来；而C# 则不显示注释。

例一

@echo off
echo 这是例一
rem 上面的echo 语句用于显示提示。
pause

这个例子中，执行步骤被off了；因此rem 后面的注释不显示，执行结果如下：

例二

但是如果将 回显 打开 ，例如这样：

@echo on
echo 这是例一
rem 上面的echo 语句用于显示提示。
pause

则执行过程中注释也会显示出来，执行结果如下：

某些时候，两个英文冒号 :: 也能用来作为注释标记，例如：

@echo on
echo 这是例一
:: 上面的echo 语句用于显示提示。
pause

执行结果，同上一步。
